Notes:

  • The page fetches files relative to this HTML file. Example: readf.html?file=test1.txt.
  • For security, browsers block fetching local files from file://. Run a local static server (instructions below).
  • Text files are shown inline; PDFs/images are embedded; other binaries offered for download.

Start a quick static server (PowerShell)

# From the repository root, run one of:
# Simple Python server (if Python installed):
python -m http.server 8000

# Or PowerShell's built-in static server (PowerShell 5.1):
# Install `http-server` with Node/npm then run:
npx http-server -p 8000

# Then open: http://localhost:8000/File_io/readf.html?file=test1.txt
